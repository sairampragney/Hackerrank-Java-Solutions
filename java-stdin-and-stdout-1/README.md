# Java Stdin and Stdout I

A beginner-level Java program that demonstrates how to read multiple integer values from **standard input (`stdin`)** using the `Scanner` class and print them to **standard output (`stdout`)**.

This challenge is part of my **HackerRank Java practice** and helps build a foundation in Java input and output.

---

## 📌 About

Most programming problems require a program to:

1. Read input provided by the user or judge.
2. Process that input.
3. Print the required output.

In Java, one of the simplest ways to read input from the keyboard or standard input stream is by using the `Scanner` class.

This challenge requires reading **three integers** from `stdin` and printing each integer on a separate line.

---

## 📝 Problem

The program receives three integers as input.

Each integer must be printed on its own line.

### Sample Input

```text
42
100
125
