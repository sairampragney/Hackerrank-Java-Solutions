# Java Output Formatting

A Java program that demonstrates how to format console output using `System.out.printf()`.

This challenge is part of my **HackerRank Java practice** and focuses on formatting strings and integers into aligned columns with fixed-width spacing and zero padding.

---

## 📌 About the Problem

The program reads three lines of input.

Each line contains:

- A `String`
- An `integer`

The output must contain two formatted columns:

1. The String, left-justified within a fixed width of 15 characters.
2. The integer, displayed using exactly 3 digits, with leading zeroes when necessary.

The output is surrounded by a line of `=` characters.
