# Java Stdin and Stdout II

A Java program that demonstrates how to read an **integer, a double, and a String** from standard input using the `Scanner` class and then print them in the required format.

This challenge is part of my **HackerRank Java practice** and builds on the input and output concepts covered in **Java Stdin and Stdout I**.

---

## 📌 About the Problem

The program receives three lines of input:

1. An integer
2. A double
3. A String

It then prints the values in a specific order:

```text
String: <String>
Double: <Double>
Int: <Integer>
