# ☕ Java - Hello World

## 📌 Problem

This HackerRank challenge introduces the basics of Java output.

The task is to complete the `main` method and print two lines to standard output:

1. `Hello, World.`
2. `Hello, Java.`

There is no input required for this problem.

---

## 💡 Solution

The solution uses Java's `System.out.println()` method to print each message on a separate line.

```java
System.out.println("Hello, World.");
System.out.println("Hello, Java.");
